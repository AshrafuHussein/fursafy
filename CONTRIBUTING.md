# Contributing to Fursafy

Thank you for your interest in Fursafy! However, please note the following:

## 🚫 Contributions Are Not Accepted

**Fursafy is a solo academic final year project** developed by **Ashrafu Hussein Hashimu** as part of the **Ordinary Diploma in Computer Science** program at **Arusha Technical College (ATC)**, Tanzania, for the **2025/2026** academic year.

This repository is **public for academic review purposes only** — to allow the project supervisor, examiners, and academic reviewers to access and evaluate the work.

### What this means:

- ❌ **Pull requests** will not be reviewed or merged
- ❌ **Feature requests** will not be considered
- ❌ **Bug reports** from external contributors will not be triaged
- ❌ **Forks for contribution purposes** are not encouraged

### Supervisor access:

The project supervisor, **Eng. Abdul Kirobo**, has **read-only access** to the repository for academic oversight and evaluation.
